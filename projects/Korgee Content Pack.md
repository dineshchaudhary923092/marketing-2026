# Korgee Content Pack

## Project Positioning

- Project: Korgee
- Angle: Korean learning web and dashboard experience for travelers and K-culture fans, built around real-world situations and practical use cases
- Voice: Calm, polished, practical
- Perspective: We
- Language: English only
- Emojis: None

## Core Narrative

- Primary story: Korgee replaces abstract language lessons with a structured learning experience built around real travel scenarios such as airport arrivals, cafes, restaurants, hotels, transit, and asking for help.
- Business relevance: The product feels more valuable because the interface is shaped around immediate use, clearer navigation, and repeatable learning moments.
- Split-post logic: Social posts should separate the marketing website, the learning framework, and the dashboard flow so each post feels specific and premium rather than overly broad.
