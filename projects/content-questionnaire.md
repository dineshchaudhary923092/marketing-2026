# Project Content Questionnaire

Use this file to collect the raw inputs needed to generate content for each project in this folder.

Goal:

- turn project work into usable copy for social media
- generate website / portfolio text
- create captions, hooks, carousels, and post ideas
- capture the story behind the project, not just the visuals

## How To Use

For each project, answer the questions below as completely as possible.

If a detail is unknown, leave it blank or mark it as `TBD`.

Use one copy of this questionnaire per project, or answer the project list section first and then fill the project blocks you need.

## Master Questions For Every Project

### 1. Project Basics

- What is the project name?
- What type of project is it?
  - website
  - mobile app
  - web app
  - dashboard
  - brand / identity
  - social content
  - other
- Who is the client or brand?
- What industry does it belong to?
- Is this a new build, redesign, or refresh?
- What stage is the project in?
  - concept
  - in progress
  - ready
  - published

### 2. Business Context

- What problem does this project solve?
- Why did this project need to exist?
- What was broken, missing, slow, confusing, or weak before this work?
- Who is the target audience?
- What action should the audience take after seeing it?

### 3. Project Story

- What is the short origin story of the project?
- What was the main goal?
- What was the hardest part?
- What was the most important design or strategy decision?
- What changed after the redesign or build?
- What is the one thing this project should be remembered for?

### 4. Product / Design Details

- What key screens, pages, or assets are included?
- What features should be mentioned?
- What UI or visual style defines the project?
- What makes the work different from similar projects?
- What design systems, components, or patterns were used?
- Were there any special technical constraints?

### 5. Proof / Results

- Is there any measurable result?
  - more signups
  - better clarity
  - faster flow
  - more leads
  - improved engagement
  - no data yet
- Are there client quotes or feedback?
- Are there before/after comparisons?
- What proof can be shown publicly?
- What should not be claimed because it is not verified?

### 6. Social Media Content Inputs

- What is the strongest hook for social media?
- What is the main visual moment?
- What is the strongest feature to show in one slide?
- What should be the first line of the caption?
- What are 3 short takeaways people should remember?
- What should people comment, save, or share?
- What CTA should be used?
  - follow for more
  - check the full project
  - DM for work
  - visit portfolio
  - book a call

### 7. Website / Portfolio Copy Inputs

- What is the one-line summary of the project?
- What is the longer description?
- What sections should the portfolio page include?
  - overview
  - challenge
  - process
  - solution
  - outcome
  - deliverables
  - testimonial
- What keywords should be included?
- What should the tone be?
  - premium
  - technical
  - friendly
  - business-focused
  - bold
  - minimal

### 8. Platform-Specific Usage

- Where should this project be used?
  - Instagram
  - Facebook
  - Behance
  - Dribbble
  - LinkedIn
  - X
  - Threads
  - Pinterest
  - website
- Do the captions need to change by platform?
- Do the visuals need to change by platform?
- Is there any platform-specific limitation or preference?

### 9. Assets And References

- Which images are final?
- Which images should be prioritized?
- Are there logos, mockups, or screenshots available?
- Are there reference projects or inspiration links?
- Is there any existing copy that should be reused or avoided?

### 10. Approval And Safety

- What can be shared publicly?
- What should remain private?
- Are there any NDA restrictions?
- Are there names, numbers, or business details that must be hidden?
- Who approves the final copy?
