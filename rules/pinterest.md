# Craftnotion Skill — Pinterest Content Strategy, Writing, and Packaging

## Purpose

Use this skill whenever creating, rewriting, reviewing, packaging, sequencing, or optimizing Pinterest content for Craftnotion.

The goal is not to repost portfolio work blindly. The goal is to turn Pinterest into a searchable, saveable, evergreen discovery engine for Craftnotion’s websites, SaaS products, dashboards, apps, MVPs, and design thinking.

A strong Pinterest content system should help Craftnotion do at least one of these:

- drive website visits
- create discovery through search and related recommendations
- build long-tail visibility around services and niches
- increase saves and board distribution
- position Craftnotion as a premium digital partner
- make portfolio work useful in a planning and inspiration context

---

## Platform Reality

Pinterest is not Dribbble.
It is not Behance.
It is not mainly a “look at our work” platform.

On Pinterest:

- search intent matters a lot
- save-worthiness matters a lot
- evergreen usefulness matters a lot
- the idea framing often matters as much as the design itself
- titles, descriptions, topics, boards, and metadata matter more than people think

Pinterest behaves more like a visual search engine than a traditional social feed.

So do not post like the viewer already knows Craftnotion.
Post like the viewer is searching for:

- SaaS dashboard inspiration
- real estate website design ideas
- fintech UI examples
- website layout ideas
- admin dashboard inspiration
- landing page examples
- app onboarding design
- modern web design for business

---

## Core Positioning

Craftnotion should come across as:

- a premium but practical design and development company
- strong in websites, SaaS, dashboards, mobile apps, web apps, and MVPs
- modern, useful, and execution-focused
- commercially aware, not only aesthetically aware
- a credible partner for startups, SMEs, and growth-stage businesses

Craftnotion should **not** come across as:

- a random moodboard account
- a feed of pretty but contextless images
- a loud marketing account
- an agency screaming CTAs in every Pin
- a portfolio repost machine with no search strategy

## Pinterest Strategy Principle

Pinterest rewards content that helps people plan, explore, compare, save, and return later.

So every Pin should sell some combination of:

1. search relevance
2. visual clarity
3. usefulness
4. save-worthiness
5. curiosity to click through

A good Pinterest content system should make someone think:

- save this for later
- this is a good reference
- this is the kind of website/app/dashboard I want
- who made this?
- I should check the site or profile

## What Every Pinterest Asset Must Include

Each finalized Pinterest asset should include these items:

1. **Pin Type**
2. **Pin Title**
3. **Pin Description**
4. **Board Placement**
5. **Topic / Keyword Angle**
6. **Image Text Strategy**
7. **Link Destination**
8. **Alt Text / Accessibility Description**

This fixed format keeps the system clean.
The creative angle can vary.

---

## Official Platform Constraints and Behaviors to Respect

When packaging content for Pinterest, remember:

- Pinterest recommends creating **fresh content weekly**
- Pinterest advises filling in **all Pin fields** when publishing
- you should include a **Pin title and description** with relevant keywords
- when available, you should add **topics** before publishing
- boards should have proper **titles and descriptions** because they can also appear in search
- Pinterest recommends using inspiring, relevant content that shows the brand in realistic settings rather than abstract imagery that does not show the brand
- Pin titles can be up to **100 characters**, though only the first portion may show in feeds
- standard Pin descriptions can be up to **800 characters**

Treat Pinterest like a search and recommendation system, not a caption afterthought.

## Universal Writing Rules

### Must do

- write clear, natural English
- lead with what the user is searching for
- make the idea or category obvious quickly
- use relevant keywords naturally
- make Pins useful enough to save
- keep branding present but not overbearing
- write titles that can work in search results
- write descriptions that help contextualize the Pin

### Must avoid

- vague aesthetic-only titles
- keyword stuffing that sounds robotic
- generic agency slogans doing all the work
- aggressive CTAs
- abstract visuals that don’t connect to the topic
- turning every Pin into an ad
- posting with no board or keyword logic

Pinterest works best when the account is built around repeatable content buckets.

Use these buckets for Craftnotion:

1. **Website Inspiration**
2. **SaaS & Dashboard Inspiration**
3. **Mobile App UX**

5. **Industry-Specific Design**

## Pin Types and How to Use Them

## 1) Portfolio Pin
Use for:

- one strong shot from a real project
- one interface
- one page section
- one dashboard
- one app screen group

Goal:

- discovery
- saves
- profile curiosity
- click-through to website or case study

Best title style:

- direct and searchable
- category + industry + angle

Example:

- Fintech Dashboard Design for LC Discounting Platform
- Premium Real Estate Website Design Example

## 2) Carousel / Multi-Image Pin
Use for:

- showing a project in steps
- before/after comparisons
- feature breakdowns
- multiple page sections
- case-study teasers

Goal:

- more time-on-Pin
- more saves
- deeper context than a single image

Best angle:

- start with the clearest thumbnail first
- each frame should add value
- do not use carousels just because you have many images

## 3) Video Pin
Use for:

- quick UI motion
- scroll walkthroughs
- app flows
- interface reveals
- short transformations

Goal:

- attention
- stronger engagement
- product feel

Best angle:

- keep it short and clear
- let motion explain the work
- avoid overly dramatic edits

## 4) Idea / Tip Pin
Use for:

- design lessons
- structure breakdowns
- website tips
- dashboard best practices
- SEO-aware educational content

Goal:

- search visibility
- saves
- authority
- broader reach beyond direct portfolio viewers

Best angle:

- teach one thing clearly
- be practical
- be saveable

## 5) Evergreen Search Pin
Use for:

- broad search phrases
- design inspiration queries
- “ideas” style content
- business planning queries

Goal:

- long-tail search traffic
- repeated impressions over time

Best angle:

- align the Pin directly with common search language
- keep the design clean and literal enough to match the search intent

Boards should be organized by discoverable themes, not random internal labels.

- Premium Website Design
- Mobile App UI Inspiration
- Fintech UI Design

- Website Design for Startups

### Bad board examples

- Our Work
- Miscellaneous
- Moodboard 2
- New Stuff
- UI Ideas Random

### Board rules

- use clear titles people would actually search
- write a board description with natural keywords
- keep each board focused
- do not mix unrelated content into one board

---

## Pin Title Rules

Pinterest titles carry serious search weight.

A good title should:

- be clear in the first few words
- match search intent
- say what the Pin actually shows
- avoid being too clever
- stay useful even without the image

### Best title formulas

- **Category + Industry + Format**
- **Modern [thing] Design for [audience/use case]**
- **[Type] Inspiration / Example / Ideas**
- **[Project] — [searchable descriptor]**

Examples:

- Fintech Dashboard Design for Trade Finance Platform
- Premium Real Estate Website Design Example
- SaaS Landing Page Inspiration for Startups
- Travel Expense Management Dashboard UI
- App Onboarding UI for Healthcare Platform

### Avoid

- brand-only titles when the brand is unknown
- vague titles like “Cool UI” or “Modern Design”
- overlong titles stuffed with every keyword
- titles that start with Craftnotion unless brand intent is the priority

---

## Pin Description Rules

Descriptions on Pinterest help contextualize the content and improve search/recommendation understanding.

A strong description should:

- clarify what the Pin is about
- naturally include relevant keywords
- support saves and clicks
- mention who it may help or inspire
- stay readable

### Description structure options

**Option A — direct and useful**
- what it is
- who it is for
- what makes it useful
- soft CTA

**Option B — search-led**
- idea framing
- relevant keywords
- practical use case
- soft CTA

**Option C — educational**
- one useful angle
- what the viewer can learn
- save-worthy framing

### Avoid

- keyword dumping
- fake urgency
- writing that sounds like ad copy
- repeating the title word for word

---

## Image Text Rules

Pinterest often benefits from image text more than Dribbble or Behance.

But it still needs discipline.

### Good image text uses

- clear topic label
- searchable descriptor
- before/after framing
- “ideas” angle
- “examples” angle
- one practical learning promise

### Examples

- Fintech Dashboard Design Example
- Premium Real Estate Website Inspiration
- 5 SaaS Landing Page Ideas
- App Onboarding UI Breakdown
- Modern Admin Dashboard Layout

### Avoid

- giant text blocks
- multiple competing messages
- noisy banners and stickers everywhere
- discount/sales language unless it is an actual campaign
- abstract headlines that don’t match user search intent

## CTA Rules

Pinterest is not the place for loud, needy CTAs.

### CTA goals

A Pinterest CTA should do one of these:

- encourage saves
- encourage click-throughs
- encourage exploration
- create inquiry intent softly

### Good CTA styles

- Save this for website inspiration.
- Explore the full project at Craftnotion.
- Visit Craftnotion to see more product and website work.
- Looking to build something similar? Let’s connect.
- See more case studies through the link.

### Avoid

- DM now
- Hire us today
- Book your slot now
- Limited spots available
- Best agency in India
- Contact immediately

Pinterest should feel useful first, promotional second.

## Keyword and Search Rules

Pinterest search strategy should be deliberate.

### Use keywords in these places

- Pin title
- Pin description
- board title
- board description
- topic tagging when available
- linked page title / metadata if relevant

### Keyword rules

- prioritize phrases people would actually search
- use long-tail phrases naturally
- match the image and the title closely
- include industry/context where useful
- do not repeat the exact phrase awkwardly 5 times

### Good keyword examples for Craftnotion

- fintech dashboard design
- SaaS landing page
- admin dashboard ui
- real estate website design
- app onboarding ui
- LMS dashboard design
- healthcare app ui
- business website design
- startup website inspiration
- travel expense dashboard

## Asset Packaging Rules

### Single-image Pins

- use a clear focal point
- keep composition readable on mobile
- use short overlay text only when it adds value
- avoid cluttered mockup walls

### Carousel Pins

- lead with the strongest frame first
- each frame should have one job
- maintain visual consistency
- do not overload the carousel with 10 mediocre slides

### Video Pins

- start with movement or a strong first frame quickly
- keep pacing clean
- avoid long intros
- make sure motion improves understanding

### Pinterest aesthetic rule

The pin should be clean enough to stop the scroll and literal enough to match the search.
Do not make the viewer work too hard to understand what they are looking at.

---

## Posting Rhythm Rules

Pinterest rewards consistency and freshness more than dramatic posting bursts.

### Best rhythm for Craftnotion

- post fresh content weekly
- repurpose one project into multiple pin angles
- mix portfolio Pins with educational Pins
- create evergreen Pins, not only launch Pins

### One project can become:

- 1 hero inspiration Pin
- 1 case-study teaser
- 1 tip / breakdown Pin
- 1 industry-targeted Pin
- 1 mobile or detail Pin

That means Pinterest is not just a dumping ground for finished work. It is a packaging engine.

---

## Linking Rules

Every Pin should link somewhere useful.

Best destinations:

- the exact case study page
- the exact service page
- the portfolio/work page
- a relevant landing page

Avoid:

- linking everything to the homepage
- linking to pages with weak context
- mismatching Pin promise and landing-page content

The user should land where the promise continues.

---

## Final Review Checklist

Before finalizing any Pinterest asset, check:

- Is the title searchable and clear?
- Would someone understand the Pin instantly?
- Is the board placement correct?
- Does the description support search naturally?
- Is the visual save-worthy?
- Is the image text clean and useful?
- Does the link destination match the promise?
- Would this work as an evergreen asset, not just a one-day post?
- Does it sound like Craftnotion, not a generic social team?

If not, fix it.
